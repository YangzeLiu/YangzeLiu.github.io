Under review · LLM agents

All under review at ICLR 2027

  1. What Does a Harness Buy? Tokens, Mostly.

    Yangze Liu and Zhongyi Han

    Across five models and three coding harnesses on SWE-bench Verified, swapping harnesses on a hard subset flipped as many tasks as rerunning the same one. The only harness effect above the noise was a loss; cost varied by up to 3× per task for the same model.

    Paper ↗ Code ↗

  2. Experience Is Not Knowledge: Where the Decision Knowledge in an Agent’s Memory Comes From

    Yangze Liu and Zhongyi Han

    I built a controlled Slay the Spire testbed that varies only the source of an agent’s memory. Self-written experience memory did not improve clear rate; memories containing correct, usable rules did.

  3. Asking Earns Nothing: Scoring the Decision to Act in BFCL Multi-Turn

    Yangze Liu and Zhongyi Han

    The BFCL multi-turn scorer skips the turn where an agent should ask for missing information. I built a judge-free decision metric and showed that an action-pushing prompt raised official scores by 13.5–23.5 points with no detectable change in decisions.

    Paper ↗ Code ↗
